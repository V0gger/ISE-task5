Задание 5
Исходные данные:
1. Имеется файл с входными данными (напр., vvod.txt), содержащий поток команд в формате (напр., Чжен-Лю, Гибсон «Микропроцессоры семейства 808618088») с возможностью модификации. Команды представляются в виде формальных выражений типа R1,R2 → R3, где R1,R2 - имена источников операндов, а R3 - имя приемника операндов (R1, R2, R3 - могут быть как регистрами, так и ячейками памяти). Поток последовательных команд - 10 команд, среди которых могут быть команды переходов.
2. Имеется файл с выходными данными (напр., vivod.txt), который должен отображать итоговую таблицу занятости (с распределением по ступеням конвейера) и итоговую таблицу занятости с переставленными командами (с распределением по ступеням конвейера).
3. Команды разных форматов имеют разные таблицы занятости (могут быть в файле vvod.txt или в другом файле с возможностью модификации).
1.1 Организовать конвейер команд по «жадной» стратегии (без нарушения логики программы).
1.2 Вычислить время выполнения последовательной программы в условных единицах с учетом конвейера.
1.3 Определить какие команды можно переставить местами не нарушая логики программы
1.4 Вычислить время выполнения последовательной программы в условных единицах с конвейером с переставленными командами.
1.5 Вычислить коэффициент роста производительности.
Все результаты записываются в файл с выходными данными (напр., vivod.txt).
